### MCP Servers to Activate
- [ ] Playwright — Browser automation for UI verification, end-to-end testing, and confirming features actually work in the running app. Install via `claude mcp add` using the Playwright MCP package; no external credentials needed.

### Skills to Know About
- /clear — Wipe the current conversation context. Use between unrelated tasks so old history doesn't pollute the next one.
- /usage — Check Claude usage/quota for the current period.
- /caveman:caveman — Terse-response mode. Drops filler, articles, and pleasantries. Toggle with "normal" or "stop caveman".
- /goal — Set the conversation's working goal so Claude stays oriented across a longer task.
- /effort — Adjust how hard Claude works on the next response (depth vs. speed tradeoff).
